# Feature: HX711 load-cell scale v1

Raw counts from an HX711 24-bit load-cell ADC over its two-wire clocked protocol ([ADR-016](../adr/016-clocked-gpio-drivers-in-tamer.md)).
The tare / scale / temperature-compensation math turns them into grams.
The consumer is the beekeeper's hive scale, four 50 kg load cells in a Wheatstone bridge, read from a Heltec S3 under ESP-IDF with Wi-Fi and LoRa running.
Ports two staged crates from a downstream project; the NAU7802, NVS storage and the calibration downlink are out of scope.

## Decisions
| Decision | Reason | Rejected Alternative |
|:--|:--|:--|
| `tamer::hx711`, feature `hx711 = []`, no dependency; driver needs `hal` too | ADR-016 placement, as ADR-009 | Driver in each tier |
| `Hx711<Dout, Sck>` over `InputPin` / `OutputPin`; delay and mask passed per call | Mirrors `Sht3x`; a stateless mask can guard several drivers | Driver owns delay and mask |
| `InterruptMask` + `NoopInterruptMask` in `tamer`; tiers add `MaskedSection` | ADR-016: the 60 µs power-down hazard is in the signature | Documented requirement only |
| esp-hal mask: `critical_section::with`; ESP-IDF mask: `IsrCriticalSection` | ESP-IDF's `critical_section` is a mutex (lore) | One `critical_section` impl in `tamer` |
| `Gain::{A128, B32, A64}` is a `read` parameter | The donor's stored gain applied one read late | `set_gain` state |
| `read` returns `NotReady` while DOUT is high instead of clocking | No garbage sample can leak | Trust the caller |
| The first sample after power-up or a gain change is the caller's to discard | A discard costs a 100 ms conversion; the consumer already does it | Automatic discard in `read` |
| `Error<ED, ES>::{Dout, Sck, NotReady}` with `Display`, as `sht3x::Error` | esp-hal pins and mocks have distinct error types | One error generic |
| `sign_extend_24` masks to 24 bits; rails and timings are named constants | Datasheet facts as data | Scattered literals |
| One `Calibration`, positional `new(tare, counts_per_gram, ref_deci_c, drift)` | Validated, panic-free (`new` returns `Result`), no behavioural `Default` | Donor's three wrapper types and `uncalibrated()` |
| `to_bytes() -> [u8; 16]` / `from_bytes() -> Option`: magic, version, LE fields | 16 bytes as requested, reference temperature as `i16` deci-°C; exact round trip | 20 bytes with an `f32` reference |
| `LoadCellScale<N>` with `weigh(raw, Option<f32>) -> f32` as the pipeline entry | The pipeline the consumer calls; `N = 1` disables averaging | The downstream project's type name, bare `Scale` |
| `smoothing::SignedSlidingAverage<N>` (`i32` samples, `i64` sum, `reset`) | Request: reuse `smoothing`; purely additive | Private ring; generic `SlidingAverage` |
| `mock::MockOutputPin` public; the scripted DOUT bit rig stays test-local | Symmetric twin of `MockInputPin`; the bit rig has one consumer | Public scripted input pin |
| Root re-exports `LoadCellScale` and, with `hal`, `Hx711` only | SHT3x precedent; `Calibration` would sit beside `AccelCalibration` | Flatten everything |
| Blocking only, no `hal-async` runner | ADR-016: no await point inside a masked pulse train | Async twin as the I2C drivers |
| `hal_c3_hx711` / `idf_c3_hx711`, DOUT GPIO 6, SCK GPIO 7, `bench/c3/hx711.toml` | I2C pogo GND / 3V3 / SDA / SCL = module GND / VCC / DT / SCK; no rewiring | DOUT GPIO 4 + SCK GPIO 1 across two pogos |
| `hal_c6_hx711` / `idf_c6_hx711`, GPIO 21 / 22 (ADR-015), `bench/c6/hx711.toml` | Second bench board with the module at hand; a C3 run never ticks a C6 cell | C3 only |

## API surface
- Pure: `Gain` (`extra_pulses()` 1 / 2 / 3, `total_pulses()` 25 / 26 / 27), `sign_extend_24(u32) -> i32`, `is_saturated(i32) -> bool`, `RAW_MIN`, `RAW_MAX`.
- Constants: `PULSE_US` 2, `POWER_DOWN_US` 60, `SETTLE_MS_10HZ` 400, `SETTLE_MS_80HZ` 50, `CALIBRATION_MAGIC`, `CALIBRATION_VERSION`.
- `Calibration::{new, identity (const), tare_offset, counts_per_gram, reference_deci_c, drift_g_per_c, tared, grams, compensate, to_bytes, from_bytes}`.
- `CalibrationError::{InvalidScale, InvalidDrift, InvalidMass}`.
- `LoadCellScale<N>::{new(Calibration), weigh, tare, calibrate, calibration, set_temperature_compensation, averaged_raw, window_len, window_is_full}`.
- `InterruptMask::masked(&self, f)`; `NoopInterruptMask`.
- Driver (`hal`): `Hx711::{new, power_up, power_down(delay), is_ready, read(delay, mask, gain), read_blocking(delay, mask, gain, max_polls), release}`; `Error<ED, ES>`.
- Tiers (`hx711` feature): `hx711::MaskedSection::new()`; `mock::MockOutputPin::{new, is_set_high, rising_edges}`.

## Constraints
- `no_std`, alloc-free, panic-free, no `unsafe` in `tamer`, MSRV 1.88; the `hx711` feature adds no dependency.
- Only the 24 + gain pulses run inside the mask; no logging, allocation or blocking there, and only a busy-wait `DelayNs` (esp-hal `Delay`, esp-idf-hal `Ets`).
- Every pin fault is an `Err`, never a panic; `read_blocking` checks DOUT `max_polls + 1` times with `max_polls` waits of 100 µs, so `max_polls = 0` is one non-blocking attempt.
- `read_blocking` holds the CPU for about `max_polls` × 100 µs: 2 000 polls is 200 ms, roughly 50 000 polls would trip the 5 s ESP-IDF task watchdog, and one 10 Hz conversion needs about 1 000.
- A pin fault inside the pulse train drives PD_SCK low and completes the train clock-only, still inside the mask, before `read` returns.
- The chip then ends the transfer with the requested gain, and the next conversion is valid.
- `power_down` holds PD_SCK high for 70 µs; `power_up` drives it low and the caller waits the settle time and discards one sample.
- The masked window is about 100 to 135 µs on both tiers for 25 to 27 pulses; the upper bound is a GPIO-overhead estimate until the rig run measures it.
- The driver clocks with `PULSE_US` = 2, because esp-hal's `Delay` quantises to whole microseconds and a 1 µs request can last under 1 µs.
  Each PD_SCK phase then lasts more than 1 µs, well above the HX711's 0.2 µs minimum and under its 50 µs maximum.

## Required tests (host)
- Pure: sign-extension fixtures `0`, `0x123456`, `0x7FFFFF`, `0x800000`, `0xFFFFFF`, high-bit garbage masked; pulse counts per gain.
- Codec: round trip, golden bytes, wrong magic / version, NaN / zero scale, non-finite drift; `tared` saturation; drift sign (30 °C vs 20 °C at 2 g/°C gives −20 g).
- Scales: `new`, `from_bytes` and `calibrate` reject subnormal and overflowing scales, accept `f32::MIN_POSITIVE`, and leave state untouched on error.
- Window: partial fill, roll-off, reset, `i32::MAX` samples without overflow, truncation toward zero; `N = 0` is a `compile_fail` doctest.
- `averaged_raw` is `None` when empty and reflects the tare offset after tare.
- `is_saturated` is true at `RAW_MIN` and `RAW_MAX` and false one count inside.
- Pipeline: the donor's 5 kg case (tare 8 000 000, 10 kg at 8 210 000, 8 105 000 reads 5 000 g ± 1 g).
- Re-tare clears the window; a failed `calibrate` leaves state untouched; `None` and NaN temperature skip compensation.
- Driver (`MockOutputPin` + a scripted DOUT): bit order and gain pulses for `0x123456` and `0x800000`; `NotReady` without clocking when DOUT is high; `Dout` / `Sck` error mapping.
- Driver: every PD_SCK edge at mask depth 1; `power_down` / `power_up` levels; `release` returns the pins.
- `read_blocking` with `max_polls = 0` reads once when ready and returns `NotReady` with zero delays when busy.
